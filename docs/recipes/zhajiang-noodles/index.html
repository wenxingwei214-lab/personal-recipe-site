炸酱面

25 分钟 简单 1 人份 家常
主食类面食炸酱拌面下饭菜

原料

  • 面条1 人份
  • 肉末适量
  • 黄瓜半根，可选
  • 甜面酱或黄豆酱适量
  • 葱姜蒜少量
  • 生抽少量，可选
  • 糖少量，可选

工具

炒锅汤锅

上次做：

步骤

  1. 黄瓜切丝备用；葱姜蒜切末。
  2. 锅里放少量油，放入肉末炒散，炒到变色出香味。
  3. 加入甜面酱或黄豆酱，小火炒香；如果偏咸，可以加一点水和少量糖调和。
  4. 酱汁炒到浓稠后关火，尝一下咸淡。
  5. 另起锅煮面，面熟后捞出，可以过一下凉水再沥干。
  6. 面条放碗里，浇上炸酱，放黄瓜丝，拌匀即可。

注意事项

  • 炸酱要小火慢炒，火太大容易糊。
  • 酱本身咸度高，生抽要少放或不放。
  • 面条捞出后尽快拌，口感更顺。

下次优化

  • 下次记录用的是甜面酱、黄豆酱还是混合酱，方便固定自己喜欢的比例。
